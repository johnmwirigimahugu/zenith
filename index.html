Zenith Framework

A production-ready single-file PHP framework for developers who value clarity, control, and speed.

Get Zenith 
<?php
require 'zenith.php';

app()->route('GET', '/', fn() => 'Hello Zenith');

app()->run();

Framework Features

Single-file architecture
MVC, Routing, Middleware
Template engine
ORM integration (RedBean-ready)
Security: CSRF, sessions, auth
Uploads, Mail, CLI utilities

Documentation

Installation: Download zenith.php and include it in your project.

composer require zenith/framework

Routing:

app()->route('POST', '/login', 'AuthController@login');

Views: Simple, secure PHP templates with layout support.
