Zenith Framework

Zenith is a minimalist, transparent framework ecosystem composed of a single-file PHP backend, a lightweight JavaScript layer, and a purpose-built CSS system. It is designed for developers who want to understand every layer of their stack. Zenith emphasizes simplicity, readability, and extensibility without external dependencies or magic.

Zenith PHP

A full MVC-capable PHP framework in a single file (zen.php), including routing, ORM, auth, caching, queue, events, logging, and CLI.

Zenith JS

A pragmatic JavaScript micro-framework for DOM manipulation, reactivity, AJAX, routing, forms, and state management without virtual DOM.

Zenith CSS

A semantic CSS foundation with utility classes for layout, components, theming, animations, and responsive design based on Material Design 3.

Philosophy

Zenith addresses modern framework complexity by returning to fundamentals: explicit code, composable helpers, and full-stack transparency. Single-file design eliminates bloat, enables quick onboarding, and encourages deep understanding.

Why Zenith?

Unlike heavy frameworks with magic methods and dependencies, Zenith is a unified "batteries-included" micro-framework across PHP/JS/CSS, similar to Flask or Sinatra but with enterprise-grade features for seamless development.

Zenith PHP Framework

Implemented in zen.php (version 3.1.6), a single-file framework providing MVC, routing, DI container, ORM, auth, validation, caching, queue, events, mail, logging, CLI, and security without dependencies.

Overview

Zenith PHP compresses capabilities of Django, Rails, Flask, and CodeIgniter into one file. It uses modern PHP 8+ features for pragmatic minimalism.

Architecture

Request lifecycle: Bootstrap → Router → Middleware → Controller → Model/DB → View → Response. Patterns: DI, MVC, ActiveRecord, Pipeline, Observer.

  • ZenApp: Application kernel
  • ZenContainer: DI container
  • ZenRouter: HTTP routing with params/middleware
  • ZenRequest/Response: Input/output handling
  • ZenView: Templating with layouts/sections
  • ZenDatabase: PDO wrapper with query builder
  • ZenModel: ActiveRecord ORM

Routing

<?php
require 'zen.php';
$app = new ZenApp();
$app->getRouter()->get('/', fn() => 'Hello Zenith!');
$app->getRouter()->get('/users/{id}', fn($id) => "User $id");
$app->run();

Controllers

Closures or classes with DI.

class UserController {
  public function show(ZenRequest $request, $id) {
    return User::find($id);
  }
}
$app->getRouter()->get('/users/{id}', [UserController::class, 'show']);

Views / Templates

PHP-based with extend/section/include.

<?php extend('layout'); ?>
<?php section('content'); ?>
  <h1>Hello, <?= $name ?>!</h1>
<?php endSection(); ?>

ORM Integration

class User extends ZenModel {
  protected $table = 'users';
  protected $fillable = ['name', 'email'];
}
$user = User::create(['name' => 'John']);
$users = User::where('active', 1)->get();

Security Features

  • CSRF protection
  • Rate limiting
  • Input sanitization
  • Secure sessions/cookies

File Uploads

Handled via ZenRequest.

Email

Zenith JavaScript Framework

Zenith JS (zen.js, version 3.1.6) is a lightweight, dependency-free framework combining reactivity, AJAX, DOM utils, icons, and CSS integration. Inspired by Alpine.js, HTMX, AJX.js, W3.js.

Purpose and Design Goals

  • No virtual DOM; direct manipulation
  • Minimal abstraction; readable source
  • Progressive enhancement
  • Python/Ruby-like brevity
  • Shallow learning curve

Differs from React/Vue: No build step, no components as classes, focuses on attributes for reactivity (zen-b, zen-t, zen-show, zen-x).

DOM Manipulation Philosophy

Direct DOM updates with utilities like zen.on, zen.text, zen.html.

State Handling

Reactive bindings via attributes; zen-b for bind, zen-t for text.

<input zen-b="name">
<p zen-t="name"></p>

Events

Pub/sub with client.events; zen-on for element events.

zen.on('#btn', 'click', () => client.flash.success('Clicked'));

AJAX

zen-ajax attribute for HTMX-like; client.ajax for programmatic.

<button zen-ajax="get:/data" zen-target="#result">Load</button>

Code Examples

zen.ready(() => {
  zen.on('#form', 'submit', e => {
    e.preventDefault();
    client.ajax.post('/submit', client.form.serialize('#form'), res => {
      client.flash.success('Submitted!');
    });
  });
});

Zenith CSS Framework

Zenith CSS (zen.css, version 3.3) is a semantic, class-light system for layout, components, and styling. Based on Material Design 3, with utilities, themes, and animations. Complements or replaces Tailwind parts.

Design Philosophy

  • Readable class names (zen- prefix)
  • Minimal overrides; strong defaults
  • Material Design 3 theming; light/dark/high-contrast
  • Responsive utilities; animations
  • Framework-agnostic

Utility Classes

Spacing (m-*, p-*), flex/grid, text, etc.

<div class="zen-container zen-flex zen-justify-center">Content</div>

Layout System

zen-flex, zen-grid, responsive cols (zen-grid-cols-2).

Components

zen-btn-*, zen-card, zen-alert-*, zen-icon, etc.

<button class="zen-btn-primary">Click</button>

How it Complements Tailwind

Provides semantic components and MD3 theming; use with Tailwind for utilities.
