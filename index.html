Zenith Framework

Zenith is a minimalist, transparent framework ecosystem composed of a single-file PHP backend, a lightweight JavaScript layer, and a purpose-built CSS system. It is designed for developers who want to understand every layer of their stack. Zenith emphasizes simplicity, readability, and extensibility without external dependencies or magic.

Zenith PHP

A full MVC-capable PHP framework in a single file, including routing, ORM, auth, and more.

Zenith JS

A pragmatic JavaScript micro-framework for DOM manipulation, state, and AJAX without virtual DOM.

Zenith CSS

A semantic CSS foundation with utility classes for layout, spacing, and components.

Philosophy

Zenith returns to fundamentals to address modern framework complexity. It promotes explicit code, composable helpers, and full-stack transparency. Why single-file? To eliminate bloat, enable quick onboarding, and encourage deep understanding over abstraction.

Comparison Mindset

Unlike heavy frameworks, Zenith avoids magic methods and external deps. It's closer to a "batteries-included" micro-framework like Flask or Sinatra, but unified across PHP/JS/CSS for seamless development.

Zenith PHP Framework

Implemented entirely in zen.php, providing routing, controllers, views, middleware, config, security, ORM, auth, caching, queue, events, logging, and CLI—without dependencies.

Core Concepts

  • Single entry point and DI container
  • Explicit routing with parameters
  • Minimal MVC with ActiveRecord ORM
  • Composable helpers (validation, auth, etc.)
  • File-based cache, session, queue
  • Event dispatcher and middleware pipeline

Architecture Overview

Request flow: Router → Middleware → Controller → Model/DB → View → Response. Uses DI, MVC, and Observer patterns.

Example: Basic Routing

<?php
require 'zen.php';
$app = new ZenApp();
$app->getRouter()->get('/', function() {
    return 'Hello, Zen Framework!';
});
$app->run();

Configuration

Environment-based config via .env, loaded into ZenConfig.

'app' => [
    'name' => 'Zen Application',
    'env' => $_ENV['APP_ENV'] ?? 'production',
    // ... database, cache, session, mail, etc.
],

ORM & Models

ActiveRecord-style with query builder.

class User extends ZenModel {
    protected $table = 'users';
    protected $fillable = ['name', 'email', 'password'];
}
$user = User::find(1);
$users = User::where('active', 1)->get();

Validation

$validator = ZenValidator::make($request->all(), [
    'name' => 'required|string|max:255',
    'email' => 'required|email|unique:users',
]);

Authentication

if ($auth->attempt(['email' => $email, 'password' => $password])) {
    return redirect('/dashboard');
}

Queue & Events

$queue->push(SendEmailJob::class, ['user_id' => $user->id]);
ZenEvent::listen('user.registered', SendWelcomeEmailListener::class);

CLI Utilities

  • php zen.php serve - Dev server
  • php zen.php migrate - Run migrations
  • php zen.php queue:work - Process jobs

Zenith JavaScript Framework

A lightweight, dependency-free framework combining reactivity, AJAX, DOM utils, and CSS integration. No virtual DOM; focuses on progressive enhancement and brevity.

Design Goals

  • No virtual DOM; direct manipulation
  • Minimal abstraction; readable source
  • Reactivity via zen-b, zen-t
  • AJAX with zen-ajax; pub/sub events
  • Components, routing, i18n, auth

Example: Basic Event Handling

zen.ready(() => {
  zen.on('#btn', 'click', () => {
    zen.text('#output', 'Hello Zenith');
  });
});

Reactivity & Templates

Use zen-tpl for dynamic content; zen-each for loops.

<div zen-each="users" zen-t="name"></div>

AJAX & Forms

client.ajax.post('/api/users', {name: 'John'}, (data) => {
  client.flash.success('User created');
});

Routing

client.router.route('/users/:id', (params) => {
  // Load user
});

Zenith CSS Framework

Semantic, class-light system for layout, spacing, and components. Complements Tailwind with readable names; framework-agnostic.

Philosophy

  • Readable class names (e.g., .zen-container)
  • Minimal overrides; strong defaults
  • Material Design 3 theming; dark mode
  • Responsive utilities; animations

Example: Layout

<div class="zen-container zen-flex zen-justify-center">
  <h1 class="zen-title">Zenith</h1>
</div>

Components

Includes cards, buttons, modals, alerts, pagination with zen- prefix.

.zen-btn-primary {
  background: var(--zen-primary);
  color: white;
}

Theming

CSS vars for primary/secondary colors; supports dark/high-contrast modes.

Introduction

Zenith provides a solid foundation for web apps with simplicity and clarity. Production-safe, easy to extend. Features: Config, DI, Routing, Middleware, Templating, ORM, Auth, Validation, Caching, Queue, Events, Logging, CLI.

Getting Started

  1. Download zen.php, place in project root.
  2. Create .env for config.
  3. Define routes in index.php.
  4. Set up server (Apache/Nginx).
  5. Generate APP_KEY.
$app->getRouter()->get('/', function() {
    return 'Hello, Zen Framework!';
});
$app->run();

Core Concepts

Request lifecycle: Router → Middleware → Controller → Model → View → Response. Components: ZenApp, ZenContainer (DI), ZenRouter, ZenRequest/Response, ZenModel (ORM), ZenView, ZenValidator, ZenAuth, ZenCache.

Routing Example

$app->getRouter()->get('/users/{id}', function($id) {
    $user = User::find($id);
    return view('user', ['user' => $user]);
});

Models

class User extends ZenModel {
    protected $table = 'users';
    protected $fillable = ['name', 'email'];
}
$users = User::query()->where('active', 1)->get();

Views

<?php extend('layouts.app') ?>
<?php section('content') ?>
    <h1>Welcome</h1>
<?php endSection() ?>

Advanced Topics

Middleware, security (CSRF, rate limiting), performance (caching), deployment. Validation: required, email, min:max, unique. Auth: attempt, user, check. Queue: push, process. Events: listen, dispatch.

Validation

$validator = ZenValidator::make($request->all(), [
    'email' => 'required|email|unique:users',
    'password' => 'required|min:6|confirmed',
]);

Best Practices

Use explicit bindings in DI; validate all inputs; leverage events for decoupling; cache queries; secure with middleware.

Deployment

Set APP_ENV=production; run migrations; configure server rewrites. CLI: php zen.php health.
